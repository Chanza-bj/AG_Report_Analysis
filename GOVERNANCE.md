# Governance

## Maintainer

Boyd Chanza is the project maintainer. The maintainer decides what is merged, what is published, and when a release is tagged.

## Decisions

- **Data corrections** are merged once the source page has been checked by a second person, or by the maintainer when no second reviewer is available.
- **Changes to method** (how a figure is counted or estimated) are discussed in an issue first and recorded in `docs/methods_and_limitations.md`.
- **Releases** are tagged with semantic versions. Patch releases fix errors; minor releases add data or cases; major releases change definitions.

## Corrections and versions

Every correction is logged in `CHANGELOG.md`. Citations should name the version tag so that later corrections do not silently change an earlier reference.

## Becoming a maintainer

Contributors who make several verified corrections and review others' work carefully may be invited to become reviewers with merge rights for data corrections.
