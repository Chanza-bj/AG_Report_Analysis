# Code of Conduct

This project analyses public spending records. Discussion should stay focused on what the documents show.

## Expected behaviour

- Be respectful and specific. Disagree with the evidence, not the person.
- Cite sources for factual claims.
- Accept corrections gracefully, and make them when you are shown to be wrong.

## Unacceptable behaviour

- Harassment, insults, or threats toward anyone, including officials, companies, or individuals named in the reports.
- Presenting an audit question as proof of crime, or publishing allegations the reports do not make.
- Publishing private personal information (addresses, identity numbers, phone numbers, or family details).
- Submitting fabricated or unverified figures as if they came from a report.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, and block contributors who repeatedly break these rules. Report concerns by opening a private security advisory on GitHub or contacting the maintainer through the repository profile.

## Right of reply

If a named organisation or person believes a record is wrong or unfair, they may ask for a correction through the *Data error* issue template. Corrections are logged in the changelog.

This code is adapted in spirit from the Contributor Covenant, version 2.1.
